# Sources

- [University of Illinois Chicago CPU Scheduling course notes](https://www.cs.uic.edu/~jbell/CourseNotes/OperatingSystems/6_CPU_Scheduling): conceptual reference for FCFS, SJF, Round Robin and scheduling metrics. The notes reference *Operating System Concepts*, ninth edition, by Silberschatz, Gagne and Galvin.
- [Oracle Java 17 API](https://docs.oracle.com/en/java/javase/17/docs/api/): standard Java collections, file I/O and language APIs.

The example workload is included in this repository. The references above explain the algorithms; no textbook code or third-party implementation was copied. Accessed 2026-09-22.

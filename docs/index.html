Scheduling rules & implementation

What changes between algorithms?

FCFS uses arrival order. SJF chooses the shortest available burst. Round Robin shares the CPU using a fixed quantum. At a quantum boundary, new arrivals enter before a preempted process is requeued.

How to read the results

Turnaround = completion − arrival. Waiting = turnaround − burst. The browser implementation is checked against the Java reference implementation. Equal arrivals retain input order.
